# 📊 Mobile Sales Dashboard – Power BI Project

Welcome to my Power BI project: **Mobile Sales Dashboard**. It demonstrates how business data can be transformed into powerful visual insights that support decision-making in sales and operations.

## 🧠 Project Objective

The goal of this dashboard is to provide a comprehensive view of mobile sales performance across multiple time dimensions, enabling business analysts and decision-makers to:
- Monitor key KPIs like **Total Sales**, **Quantity Sold**, **Average Price**, and **Transactions**
- Compare current year sales against **Same Period Last Year (SPLY)**
- Track sales trends across **years, quarters, and months**
- Filter data by **Mobile Model**, **Payment Method**, and **Calendar Dimensions**

---

## 📌 Key Features

✅ Slicers for interactive filtering by:
- **Mobile Model**
- **Payment Method**
- **Year / Quarter / Month / Day**

✅ KPI Cards:
- **Total Sales** (769M)
- **Total Quantity Sold** (19K)
- **Transactions** (4K)
- **Average Price** (40.11K)

✅ Trend Visuals:
- Year-over-Year comparison of **Total Sales vs. Same Period Last Year**
- Monthly and Quarterly breakdowns
- Dynamic reporting using bookmarks and drill-downs

✅ Tables:
- Detailed summary of sales by **Year & Quarter**
- SPLY calculations for analytical context
